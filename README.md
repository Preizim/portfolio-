## Publish free with GitHub Pages
1. Create/sign in to GitHub: https://github.com/
2. Create a public repository, e.g. `alase-praise-portfolio`.
3. Upload `index.html`, `portrait.png`, the three project screenshots, and `README.md` to the repository root. Keep the image beside the HTML file.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
6. Wait for deployment. The URL will resemble `https://YOUR-USERNAME.github.io/alase-praise-portfolio/`.
7. Test on mobile and desktop.

Before publishing, update case studies with accurate project details and real screenshots/results. Never publish credentials, API keys or private customer data.
